📁 Supported File Types

1. Images (PNG, JPG, JPEG)

  • Detection: Google Magika file type detection
  • Processing: Image captioning via Moondream API (if MOONDREAM_API_KEY is set)
  • Storage: Original image → R2, Caption → metadata.caption in D1
  • Searchable: Filename, hashes, caption text

2. PDFs

  • Detection: Google Magika file type detection
  • Text Extraction: Page-by-page text extraction using unpdf
  • OCR Trigger: Automatic OCR if any page has < 50 characters AND total text < 1000 chars
  • OCR Method:
    1. Extract embedded images from PDF using pdf-lib
    2. Run Llama 3.2 Vision model on each image
    3. Combine OCR'd text from all images
  • Summarization: First 4000 chars sent to Llama 3.1 Fast for summary
  • Storage: Original PDF → R2, Text/OCR → metadata.rawText, Summary → metadata.summary
  • Searchable: Filename, hashes, raw text, summary
⚠️ OCR Costs: When OCR is triggered, each embedded image requires one vision model inference. A 100-page scanned PDF with 1 image per page = 100 inferences. Monitor costs in your Cloudflare dashboard.

3. All Other Files

  • Detection: Google Magika file type detection
  • Processing: Hashing only (SHA-256 + ssdeep)
  • Storage: Original file → R2, Basic metadata → D1
  • Searchable: Filename, hashes

⚙️ Processing Steps

Step Description Details
1. Validation Check file size and content Max 100 MB, must not be empty
2. Hashing Generate file fingerprints SHA-256 (exact match), ssdeep (fuzzy match)
3. Type Detection Identify file type Google Magika ML model
4. Content Processing Extract meaningful data Images → Captions, PDFs → Text/OCR/Summary, Other → None
5. Storage Persist file and metadata R2 for files, D1 for metadata

🔍 Search Capabilities

Search queries match across:

  1. Filename (partial match)
  2. SHA-256 hash (exact match)
  3. ssdeep hash (exact match)
  4. Image captions (partial match)
  5. PDF summaries (partial match)
  6. PDF raw text/OCR (partial match)
ℹ️ Search Results: Limited to 50 files, sorted by newest first.

🔧 Admin Features

The admin dashboard (/admin) provides:

  • View all uploaded files with detailed metadata
  • Multi-select file deletion
  • Delete from both R2 and D1 simultaneously
  • Detailed error messages for failed operations
  • Statistics (total files, total storage used)
  • Bulk operations support
  • Metadata Health Check - Scan for files with outdated or missing metadata
  • Reprocessing - Selectively update metadata without re-uploading files

🔄 Metadata Backfilling System

Overview

SkyDrive includes a metadata backfilling system that allows you to update file metadata when:

  • New processing features are added (e.g., OCR for PDFs)
  • Schema versions are updated with new required fields
  • Files were uploaded before certain features existed
  • Processing failed and needs to be retried

Schema Versioning

Each file type has a schema version stored in metadata (_schemaVersion):

File Type Current Version Required Fields Optional Fields
PDF v2 rawText, summary, ocrPerformed pageCount, author, title
PNG/JPG/JPEG v1 caption dimensions, colorSpace, exifData

Reprocessing Workflow

The reprocessing workflow (FileReprocessingWorkflow) performs selective updates:

  1. Fetch File: Retrieves file from R2 and metadata from D1
  2. Detect Missing Fields: Compares metadata against current schema
  3. Selective Processing: Only processes missing/outdated fields
    • PDF: Re-extract text if rawText missing, perform OCR if needed, regenerate summary
    • Image: Re-caption with Moondream if caption missing
  4. Merge Metadata: Preserves existing fields, adds new fields
  5. Update D1: Stores updated metadata with current schema version
ℹ️ No Re-Upload Required: Reprocessing fetches files from R2 storage - you don't need to re-upload files to update their metadata.

Admin Workflow

  1. Scan: Click "Scan for Outdated Files" in admin dashboard
  2. Review: See breakdown by issue type:
    • Missing Schema Version: Files from before versioning was added
    • Outdated Schema: Files with old schema version
    • Missing Fields: Files missing required fields
  3. Reprocess:
    • Individual: Click "Reprocess" button for specific files
    • Batch: Click "Reprocess All" to update all outdated files
  4. Monitor: Reprocessing runs as a background workflow - check status in logs
⚠️ Cost Considerations: Reprocessing triggers AI model inferences (OCR, captioning, summarization). For PDFs with many pages requiring OCR, costs can add up. Review the breakdown before batch reprocessing.

API Endpoints
